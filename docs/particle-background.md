# 控制台粒子效果

## 最终形态

- 控制台固定使用夜间主题，不再提供浅色模式切换。
- 全屏背景固定为 4000 个粒子。
- 每张卡片固定拥有 36 个独立粒子。
- 粒子移动速度为上一版的 2/3，单个粒子视觉尺寸缩小到 2/3。
- 视觉调整为低饱和冷蓝、淡紫、微青星点，并加入少量柔和光晕与闪烁。
- 星点核心亮度提高，但尺寸保持不变。
- 背景加入 2 组独立漂浮数学星座曲线：一组 `sin(x)` 形态，一组 Lissajous 形态。
- 星座线宽降为 1px，亮度提高到上一版的约 2 倍，并缓慢淡入淡出。
- 背景增加极淡星云和科技网格层。
- 每张卡片支持悬停上浮、冰青边框和增强阴影。
- Navbar 只保留“粒子”和“省电”两个开关。
- 已删除粒子核心、技术规格和独立“粒子背景”工作区。
- 桌面应用不包含启动浏览器或 Web UI 的入口。

## 实现位置

| 文件 | 作用 |
| --- | --- |
| `console_particles.py` | 客户端动画层、静态省电层、轻量鼠标视差 |
| `ui_theme.py` | 卡片半透明表面与悬停动效 |
| `mod.py` | 夜间主题固定、Navbar 两开关、页面导航 |
| `assets/particles/` | 已生成的透明循环 WebP 和静态 PNG |
| `tools/generate_particle_assets.py` | 确定性生成粒子动画资源 |
| `background/` | 仅供外部网站选配的 Three.js 粒子源码，不被桌面应用启动 |

## 粒子动画

粒子帧由 `tools/generate_particle_assets.py` 预先计算，并保存为 1600×900
透明循环 WebP。显示时使用 Flutter 高质量缩放，避免低分辨率放大后发糊。
Flutter 在客户端直接播放这些帧，Python 不再每 100ms 序列化数千个坐标。

- 背景：40 帧、每帧 75ms 的无缝循环；
- 卡片：40 帧透明循环；
- 星座：独立 36 帧、每帧 140ms 的 5 秒循环；
- 移动振幅缩小为之前的 2/3；
- 普通星点保持 1px 级别，少量亮星带低透明度光晕；
- 性能模式：播放 WebP 动画；
- 省电模式：切换为完全相同的静态 PNG 首帧。

## 卡片悬停

`ui_theme.card()` 为所有卡片统一添加：

- `offset.y = -0.025` 的轻微上浮；
- 160ms ease-out 动画；
- 琥珀色半透明边框；
- 更大、更柔和的阴影；
- 鼠标离开后自动恢复原位。

该效果不改变布局尺寸，不会挤压表格或其他卡片。

## 鼠标视差

控制台根层使用 `ft.GestureDetector(on_hover=...)` 获取鼠标位置：

```python
ndc_x = (local_x / width) * 2 - 1
ndc_y = -(local_y / height) * 2 + 1
target_x = clamp(ndc_x * 0.5, -0.5, 0.5)
target_y = clamp(ndc_y * 0.5 * 0.6, -0.5, 0.5)
```

相机目标仍经过 clamp 和事件间 lerp，但只更新背景容器的一个位置属性：

```python
parallax_x += (target_x - parallax_x) * 0.22
parallax_y += (target_y - parallax_y) * 0.22
```

窄于 768px 或移动平台会自动禁用视差。

## 性能模式

- 性能模式：动画由 Flutter 客户端播放，Python 帧更新为零。
- 省电模式：显示静态 PNG，不运行动画解码。
- 粒子关闭：隐藏背景和卡片粒子层。
- 悬停视差最多每 50ms 发送一次鼠标位置，只更新一个背景容器。

## 验收清单（25 条）

1. 应用启动后始终是夜间主题，不再出现主题切换按钮。
2. Navbar 只出现“粒子”和“省电”两个开关。
3. 关闭“粒子”后，全屏背景与所有卡片粒子一起隐藏。
4. 重新打开“粒子”后，背景与卡片粒子恢复，无重复图层。
5. 概览、候选池、快照复盘、自选池、持仓维护均有全屏粒子背景。
6. 每个工作区中的卡片都有独立的 36 个卡片粒子。
7. 卡片内不再出现长距离连接线。
8. 全屏粒子数量固定为 4000，不显示数量选择器。
9. 粒子移动速度比上一版慢约 1/3，仍能看出缓慢漂移。
10. 粒子移动由客户端动画播放，Python 日志中不再出现连续帧更新。
11. 鼠标移动时背景存在轻微、平滑的视差。
12. 视差偏移不超过 `[-0.5, 0.5]`，快速移动不抖动。
13. 宽度小于 768px 时视差自动停止。
14. 鼠标进入任意卡片时，卡片向上移动并出现金色边框。
15. 鼠标离开卡片后，位置、边框和阴影平滑恢复。
16. 卡片悬停不会改变网格布局或遮挡相邻卡片内容。
17. 侧边栏不再出现“粒子背景”入口。
18. 页面中不再存在粒子核心、金色核心高亮或技术规格面板。
19. 点击应用内任何按钮都不会启动浏览器、WebView 或本地 HTTP 页面。
20. 粒子边缘清晰，没有低分辨率放大造成的块状或明显模糊。
21. 单个粒子尺寸约为上一版的 2/3，整体呈细碎星点而不是大面积光斑。
22. 少数亮星存在柔和光晕和轻微闪烁，整体保持神秘、梦幻的星空感。
23. 省电模式下显示静态粒子，CPU/GPU 占用低于性能模式。
24. 快速移动鼠标时卡片 hover、按钮和表格仍能正常响应。
25. 在 1576×944 窗口下，叠加 4000 背景粒子后移动鼠标无明显排队延迟。
