# 深空青蓝视觉系统与开屏

## 工作区

- 固定夜间主题，页面背景为 `#030711`
- 主强调色为冰青 `#3DEBFF`
- 次强调色为电光紫 `#7B61FF`
- 正收益为冷绿 `#35D9A1`
- 风险与强赎为珊瑚红 `#FF647C`
- 顶部包含 `MARKET FEED`、本地快照同步、时间和粒子状态 HUD
- 卡片使用深蓝玻璃、渐变边缘、四角 HUD 标记和 hover 上浮
- 侧边栏激活项使用冰青发光竖线

## 开屏时间线

每次启动固定播放 7.5 秒，点击任意位置可跳过：

| 时间 | 内容 |
| --- | --- |
| `0.0–0.72s` | 深空背景、启动准星与星点向中心汇聚 |
| `0.6–1.0s` | 星点汇聚 |
| `1.0–3.35s` | 三波原生射线依次发射，全部越过屏幕边缘 |
| `2.4–3.35s` | HUD 环在射线后方组装 |
| `3.35s` | 强制清空所有射线控件 |
| `3.35–4.35s` | 无射线停顿 1 秒 |
| `4.35–5.15s` | 标题显现 |
| `5.15–6.05s` | 四条启动状态依次点亮 |
| `6.05–7.15s` | 进度完成并停留 |
| `7.15–7.5s` | 淡出并进入工作区 |

动画由一个客户端 HUD 层和 Flet 原生射线、文字及进度组合：

- `intro-hud.webp`：透明 HUD 环和脉冲
- `splash_intro.py`：三波原生射线、标题、状态文字和 7.5 秒时间线

## 粒子层

```text
星云静态层
4000 粒子动态层
漂浮星座动态层
科技网格静态层
```

- 星点亮度提高，但尺寸不变。
- 星座层同时最多显示 2 组数学曲线。
- 一组为 `sin(x)` 形态，另一组为 Lissajous 形态。
- 连线宽度固定为 1px，最大亮度约为上一版的 2 倍。
- 星座组整体漂浮并缓慢淡入淡出。
- 性能模式播放客户端动画，省电模式只显示静态帧。

## 验收

1. 每次启动都播放完整 7.5 秒开屏。
2. 点击开屏可立即跳过。
3. 开屏覆盖完整窗口，不露出底层界面。
4. 标题、状态文字和进度清晰，不依赖图片文字。
5. 开屏结束约 300ms 内进入工作区。
6. 工作区不存在黄色主按钮或黄色选中态。
7. 卡片具有渐变边框、角标和冰青 hover。
8. 星空亮度高于上一版，粒子尺寸没有放大。
9. 背景中可看到短小的漂浮星座连线。
10. 星座连线会淡入淡出，不会形成密集蜘蛛网。
11. 星云和科技网格不会影响文字与表格可读性。
12. 性能模式不产生 Python 逐帧动画负载。
13. 省电模式保持静态星空与星座。
14. 扫描 HUD、开屏和工作区使用一致的青蓝视觉语言。
